Resumen
-------
Este repositorio contiene el trabajo del Proyecto Intermodular del módulo de Desarrollo de Aplicaciones Multiplataforma (DAM) — curso 2. El objetivo del proyecto es diseñar, implementar y documentar una aplicación/intercambio entre módulos siguiendo las especificaciones del enunciado del módulo.

Cómo ejecutar el proyecto
-------------------------
(Instrucciones generales — adapta a tu stack)
1. Clonar el repositorio:
   git clone https://github.com/lsmaeel/Proyecto-Intermodular-DAM-2.git
2. Entrar en el directorio correspondiente:
   cd Proyecto-Intermodular-DAM-2/app
3. Instalar dependencias (ejemplo con npm):
   npm install
4. Ejecutar la aplicación:
   npm start
5. Para el backend (si aplica):
   cd ../backend
   configurar variables de entorno en `.env`
   npm install
   npm run dev
